# @intentgraph/agent-skill

The Agent Skills package for IntentGraph. Drop into `.claude/skills/intentgraph/` (Claude Code) or `.codex/skills/intentgraph/` (Codex). Both clients see the same MCP surface served by `@intentgraph/skill`.

## Install

```bash
npm install -g @intentgraph/agent-skill
# then symlink or copy this package's directory into your CLI's skills folder
```

See [`SKILL.md`](./SKILL.md) for the Claude Code manifest and [`agents/openai.yaml`](./agents/openai.yaml) for the Codex one.
