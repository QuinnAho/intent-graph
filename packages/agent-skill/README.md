# @intentgraph/agent-skill

The Agent Skills package for IntentGraph. Drop into `.claude/skills/intentgraph/` (Claude Code). It serves the MCP surface from `@intentgraph/skill`.

## Install

```bash
npm install -g @intentgraph/agent-skill
# then symlink or copy this package's directory into .claude/skills/
```

See [`SKILL.md`](./SKILL.md) for the Claude Code manifest.
